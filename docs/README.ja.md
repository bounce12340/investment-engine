# 🛡️ Investment-Engine: 機関向けクオンツ-ファンダメンタル統合プラットフォーム

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)](https://www.python.org/)

機関グレードの投資監視・評価フレームワーク。定量的リスクセンシングと定性的ファンダメンタル分析を統合。

従来のポートフォリオはラグ指標（P/Eレシオ等）に依存しますが、**Investment-Engine**は**先行指標**、**パラダイムシフト**、**確率的評価**に焦点を当て、市場価格の織り込み前に動きを予測します。

## 🚀 コアアーキテクチャ

エンジンは3層のインテリジェンススタックで動作：

### 1. ホライゾンセンシング層（マルチタイムフレーム）
3つの異なる時間軸で資産を監視：
- **短期**：流動性、センチメント、オプションスキュー
- **中期**：ファンダメンタル転換点（AI ROI、推論移行など）
- **長期**：パラダイムシフト（アルゴリズム効率、堀の侵食など）

### 2. リスク軽減層（レッド・ブルーチーム分析）
確証バイアスに対抗するため、「レッド・ブルーチーム」分析を採用：
- **ブルーチーム**：投資論を支持する証拠を収集
- **レッドチーム**：強制退場をトリガーする「キルスイッチ」（反証拠）を積極的に探索

### 3. 評価層（三角測量）
単一ポイントの価格目標を避け、3つのモデルで三角測量：
- **確率シナリオモデル**：複数の結果（強気/ベース/弱気）を加重
- **2段階DCF**：成長減衰に基づく本質的価値を予測
- **相対マルチプル**：業界ピアとの比較

## 🛠️ 主な機能

| 機能 | 説明 |
|------|------|
| **戦略的先行指標** | 高インパクト指標の専門追跡（CUDA優位性、クラウドCapEx ROI） |
| **マージンストレステスト** | レバレッジ/マージンデータを統合し、維持マージンとマージンコールリスクを監視 |
| **Obsidian統合** | 構造化された週次レポートを個人ナレッジベースに自動生成 |
| **定量的グラデーション** | バイナリトリガーではなく、緑→黄→赤のグラデーションでトレンド減衰を感知 |
| **レッド・ブルーチーム分析** | 敵対的論点テストで確証バイアスに対抗 |
| **マルチモデル評価** | DCF、確率シナリオ、相対マルチプルを三角測量 |

## 🚦 クイックスタート

### 前提条件

- Python 3.10+
- Node.js（Obsidian統合用）

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/bounce12340/investment-engine.git
cd investment-engine

# 依存関係をインストール
pip install -r requirements.txt

# 環境設定
cp .env.example .env
# .envを編集してAPIキーを設定
```

### クイックスタート

```python
from investment_watcher import InvestmentWatcher

# エンジンを初期化
watcher = InvestmentWatcher(config_path="data/monitor-registry.json")

# 週次分析を実行
report = watcher.run_weekly_analysis()

# Obsidianにエクスポート
watcher.export_to_obsidian(vault_path="~/Documents/Vault")
```
